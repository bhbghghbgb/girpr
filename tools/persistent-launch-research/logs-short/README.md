# Sanitized short log excerpts

`key-lines.md` is generated by `../scripts/make_short.py` from the gitignored
full game logs under `../logs/` (which the collection scripts copy from
`%LOCALAPPDATA%\miHoYo\Genshin Impact\`). It keeps only whitelisted lines
(`IsBaseResVersionHashChanged`, `File num to verify`, `CheckAllFinish`,
dispatch/download stages, revision/code-switch writes), truncates long JSON and
redacts any line containing a ticket, token, cookie or uid.

Do not expect full logs here. To get them, run `scripts/collect_after_launch.py`
again (the game rotates `output_log.txt` on every launch, so copy before the
next launch), then `python scripts/make_short.py` to refresh this directory.
