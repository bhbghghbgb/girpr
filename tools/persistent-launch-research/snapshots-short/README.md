# Compact marker-value excerpts

`marker-values.md` is generated by `../scripts/make_short.py` from the gitignored
full snapshots under `../snapshots/` (E: baseline markers, F: after first launch,
F: after ablation A). It contains the small text marker values and MD5s of the
manifests, **not** the full inventories or full manifest files.

Regenerate the full data with `scripts/snapshot.py`,
`scripts/collect_after_launch.py` and `scripts/ablation.py`; regenerate this
summary with `python scripts/make_short.py`. See `../notes/PROCESS.md`.
