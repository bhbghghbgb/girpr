# Short summaries of the generated `notes/*.txt` dumps

The full machine-generated dumps (`torrent-files.txt`, `copies-diff.txt`,
`manifest-analysis.txt`, `*-diff.txt`) are **gitignored** and stay where the
scripts wrote them, under `notes/`. This directory holds only hand-written,
relevant extracts; each file states where the full version comes from and how to
regenerate it. See `../notes/PROCESS.md`.
